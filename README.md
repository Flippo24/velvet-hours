# Velvet Hours

Multiplattform-Projekt für ein stilisiertes, erwachsenes 2D-Managementspiel.

## Status

Die erste Browserfassung ist spielbar. Die Character-Bible dokumentiert 14 Figuren mit Prompts und Wiedererkennungsmerkmalen.

Der Browser-Prototyp befindet sich unter `web/index.html`. Weitere Quellen und Charakterunterlagen werden im folgenden Import-Schritt ergänzt.
