## PNGs nachtragen

Nach dem Entpacken des vollständigen Projektarchivs in einen lokalen Git-Checkout:

```bash
git add assets/reference/characters/*.png
git commit -m "assets: add canonical character reference PNGs"
git push origin main
```

Die Originalgrafiken sollten bei zukünftigen Varianten als primäre Bildreferenzen verwendet werden.
