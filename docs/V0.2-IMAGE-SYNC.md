# v0.2-Bilder von ZIP nach GitHub synchronisieren

Das Gesamtarchiv enthält alle 40 neu illustrierten Charakterbögen. Der GitHub-Connector hat nur die Profile und Prompts hochgeladen, nicht die Original-PNGs.

1. Das vollständige Archiv entpacken.
2. Das GitHub-Repository lokal klonen: `git clone https://github.com/Flippo24/velvet-hours.git`.
3. Das im ZIP enthaltene Skript `scripts/sync-v02-images.sh` mit zwei Parametern ausführen: Pfad zum entpackten `velvet-hours-v0.2`-Ordner und Pfad zum Git-Checkout.
4. Die staged Änderungen prüfen, `git commit -m "assets(v0.2): add canonical noir character PNGs"` und `git push origin main` ausführen.

Das Skript prüft die SHA-256-Summen der Originaldateien, kopiert sie und staged sie, ohne eigenständig zu pushen.
