# Bilddaten nach GitHub übertragen

Das vollständige Velvet-Hours-v0.2-Archiv enthält 50 kanonische PNG-Dateien. Die GitHub-Anbindung hat bislang nur Profile und Promptdaten übertragen.

1. Beide Archivteile herunterladen und mit `cat velvet-hours-v0.2-batches-01-05-50-charaktere.zip.{01,02}.part > velvet-hours-v0.2.zip` zusammenfügen.
2. Archiv entpacken.
3. GitHub-Repository lokal klonen oder aktualisieren.
4. `bash velvet-hours-v0.2/scripts/sync-v02-images.sh velvet-hours-v0.2 /pfad/zum/velvet-hours-checkout` ausführen.
5. Bei erfolgreicher SHA-256-Prüfung die vorgemerkten PNGs mit `git commit -m 'assets(v0.2): import 50 canonical character PNGs'` committen und `git push origin main` ausführen.

Das Skript kopiert und staged die Dateien, ohne von sich aus einen Remote-Push durchzuführen.
